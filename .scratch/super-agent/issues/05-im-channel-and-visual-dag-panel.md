# 05: 人机交互信道（IM 对接）与可视化 Plan DAG / 文档树面板设计

Type: grilling
Status: resolved
Blocked by: 01, 02, 03, 06

## Answer

### 入口布局、首次引导与多项目

- 插件在 DSH 左侧顶栏（`sidebar.panellist`，与「插件」「自动化任务」并列）注册「研发中枢」入口，**不替换或魔改 DSH 原生「工作区」标题栏及列表**，仅在原生会话行上附加流程状态角标与悬停卡片。
- **首次上手强制引导（3 步向导）**：未完成初始化前禁用「新建项目 / 发起流程」：① 连接并验证 GitHub（首版仅默认支持 GitHub，配置后的账号与仓库上下文自动注入中枢与所有 Worker）；② 配置后端模型、前端模型及可选轻量检索小模型；③ 确认默认预算/并发预设并提示本地运行边界。
- **单桌面多项目与微调对话**：进入「研发中枢」主面板后可查看历史项目列表与分端进度、切换项目或新建项目；各项目独立绑定本地工作区、GitHub 仓库、授权预设与持久化状态。发起或对齐需求时复用 DSH 原生对话栏并微调：顶部加项目/阶段状态条与一键打开右侧 Plan DAG 按钮，对话流内嵌入交棒确认与受控凭据/配置卡片。
- **双运行模式**：默认本地桌面模式随 DSH 窗口运行，关闭软件或关机时暂停执行与监听并在重开后断点恢复，界面明确提示该边界；同时支持可选的服务器 24 小时常驻（headless profile）部署，桌面端可连接该后台读取同一状态。
- 飞书可选：有权限者选定项目及目标私聊或群话题，收到一次绑定确认后即可在该处接续。不绑定 IM 也能启动、收提问、回复和验收。
- 两个入口读取同一份项目状态；Worker 不各自拉群或向用户索要指令。绑定决定消息发到哪里，不代表群成员取得项目操作权限，也不把私聊内容自动转发到群里。
- 首发 IM 为飞书。通道契约涵盖绑定、按身份接收回复、向指定话题发消息及链接回项目。不能提供可信确认卡的通道退化为纯文本摘要和受权限控制的操作链接，不以普通文本模拟批准。个人微信和企业微信连接器均不属于首发交付。

### 中枢什么时候说话

- 主动推送限于三类：确需人行动（产品意图缺失或凭据阻塞）、受影响工作因额度暂停、计划交付。消息写明哪件工作、影响范围，以及需要的动作或可用的结果；同一卡点持续存在不重复催促。逐票进度、技术重试、审查和关票更新面板，用户可随时主动查询。
- 例如三张独立票并行，仅「支付回调」缺测试账号：面板显示「进行中 · 2 张执行中，1 张待你处理」；中枢只发一次配置入口。它不索要聊天中的密钥，不把另两张票暂停。补齐后重新验证，仅在条件满足时解除阻塞。
- 完成交付时指向已验证的产物；若生产发布在范围内，另列实际发布和验证结果，不把已合入写成已上线。
- 持续维护时，只在项目已授权的群、话题和规则范围内主动核查或派工，无须每次被点名。未匹配规则的闲聊不启动工作；重复反馈关联已有票。读取消息、被邀请入群、收到引用或转发都不构成额外授权。

### 聊天中的干预与授权

- 已授权者可在聊天中查询、暂停或恢复。点名一张票时，停止该分支的新派工、合入和发布；依赖它的后继仍等待，无关票继续。明确要求全停则作用于整个计划。在途操作分清已请求停止、已停止和已经发生，不承诺自动撤回已发生的发布。
- 要求改需求时，中枢指出受影响的票和失效的验收依据，再按新要求重排；指代不清时只澄清必要的范围。恢复不会绕过仍缺的凭据、未满足的依赖或已耗尽的额度。
- **允许在 IM 内批准配置变更**：调高额度或扩大主动监听范围时，确认卡明示项目、对象、当前值、新值及生效影响。有权限者可在卡内直接批准，不强制跳转网页。由插件核验真实操作者、作用域和配置版本；重复点击只生效一次，过期、已被取代或未授权的确认不生效。转发的卡片、聊天中的「同意」或中枢的文字转述不代替授权。
- 设置页同样能完成确认；两入口展示同一生效结果。调额不等于授予上线权限。凭据通过受控配置入口提供，通知和确认卡不展示密钥。

### 面板默认视图

- 首屏回答「哪个项目、哪些工作需要我」。依赖图默认展开执行中、待人处理的票和它们的直接依赖，已交付和较远分支可折叠；保留「查看全图」，并支持在总览与依赖图按端展示**后端票数 / 前端票数及各自完成进度**。同一张票只画一个节点，多项前置用多条边表示。
- 节点展示票名、执行角色（前端/后端）、当前动作和等待原因：例如「规范／规格审查中」「等支付回调接口合入」「待配置测试账号」。高亮可以用颜色辅助，但不用颜色代替文字。只有整个计划已暂停或没有可推进的工作时，才把等待标在计划层。
- 点击节点在详情抽屉显示对应验收条件、工作树、执行与审查状态、接口契约引用、验证及产物入口。文档树另设入口（也可在原生对话右侧边栏停靠打开），默认显示主干与已合入接口契约；从票据查看候选文档时标清工作树和未合入状态。两种树不混画。
- 票据详情分别显示各 Session 的上下文快照和累计 token；计划／项目视图显示去重汇总及不能归到单票的共享开销，带采样时间、来源及实测／估算／未知标记，缺失不显示为零。设置页集中提供前后端/小模型分工修改、自定义 Skills 启停与版本状态、默认预设、自定义覆盖、GitHub/飞书及运行模式配置。口径见[会话计量能力](./06-session-metering-capabilities.md)；面板和中枢读同一份数据，不各算一遍。
