## 验收条件

- [ ] 消费后端接口渲染一张含多前置后端票、前端后置依赖票、已交付较远分支及待配置账号的图；默认展开执行中/待人及其直接依赖，切换全图可见其余节点。一票只画一次，多前置有多条边。
- [ ] 页面顶部与筛选栏明确统计并展示后端票数、前端票数及各自完成进度，支持按 `backend` / `frontend` 过滤；不用颜色也能读到票名、执行角色、「等前置接口合入」「待配置账号」等当前动作和等待原因。局部等待时计划仍显示进行中；全停或确无可推进工作才标计划等待。
- [ ] 从主面板或原生对话右侧停靠 Tab 点击节点打开详情抽屉，可定位验收、工作树、接口契约文档引用、执行和两路审查、验证证据、单票计量和产物入口；尚无产物据实说明。依赖与文档导航是不同入口，不混成一棵树。
