# 31: 后端 · 落地前后端与小模型角色路由及自定义 Skills 管理

**执行角色：** backend

**What to build:** 后端支持引导与设置中分别配置「后端开发模型」「前端开发模型」和「可选轻量检索小模型」，并在派工及检索任务中按配置路由到真实会话模型；同时提供用户/团队自定义 Skills 的读取、启停与版本绑定后端接口与契约文档。

**Blocked by:** [09 按 Frontier 与空槽原子派工](09-frontier-claims.md)；[21 让共享规则通过独立维护票生效](21-rule-pinning.md)；[30 后端 · 支持多项目隔离、强制 GitHub 引导状态与双运行模式](30-multi-project-onboarding-runtime.md)

**Status:** ready-for-agent

**GitHub 实施票：** [#32](https://github.com/linxiovo/deepseek-harness-dev-hub/issues/32)

**对应规格：** [S20](../spec.md#s20)、[S30](../spec.md#s30)

**依赖理由：** 09 提供按标签认领派工出口，21 提供共享规则与自定义 Skills 版本锁定机制，30 提供多项目配置边界与新手引导闸门。

## 验收条件

- [ ] 未配置或仅配置单个开发模型（缺少前端模型或后端模型）时，引导校验不通过且禁止启动项目派工；允许两项分别指向不同模型，小模型留空时允许通过并回退默认模型。
- [ ] 同时派发标注 `backend` 与 `frontend` 的两张票：检查各自 Worker Session 的实际初始模型选择记录与调用配置，确认分别绑定后端模型与前端模型；配置了小模型时，代码库检索、Doc Tree 路由定位与状态摘要优先调用小模型。
- [ ] 注册并启用一份用户自定义 Skill，新建项目或新派发任务挂载并锁定该版本；修改或停用后不影响运行中任务，并提供完整模型配置与自定义 Skills 管理接口文档。
