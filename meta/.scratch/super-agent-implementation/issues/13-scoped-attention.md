**Blocked by:** [01 收紧 Hub Agent 工具与对外消息边界](01-hub-tool-boundary.md)；[09 按 Frontier 与空槽原子派工](09-frontier-claims.md)

**Status:** ready-for-agent

**GitHub 实施票：** [#14](https://github.com/linxiovo/deepseek-harness-dev-hub/issues/14)

**对应规格：** [S21](../spec.md#s21)

## 验收条件

- [ ] A/B/C 同时执行，仅 B 缺测试账号。中枢对话通知与后端状态接口返回「2 张执行中，1 张待你处理」及指向 B 的受控配置入口引用；A、C 仍可推进，B 的后继等待。
- [ ] 同一卡点的重复报告/重新投递只发出一次行动请求，含票名、影响范围、动作，不在聊天索要或显示密钥。只保存配置但验证仍失败时 B 保持等待；验证成功才可继续。
- [ ] 仅将确需人行动、额度暂停、计划交付列为主动推送类别；产品意图问题在 Harness 可答，例行进度、技术失败重试、审查、关票只更新可查询状态。实际额度/交付事件由相应切片接入这条通路。
