# 07: 没有新任务时，是否主动做仓库巡检

Type: grilling
Status: resolved
Blocked by: 02, 03, 05

## Answer

首版支持可选的仓库巡检，**默认关闭**。没有新任务或外部事件时，中枢不会仅因项目空闲就扫描仓库。关闭定时巡检不免除[每张实现票的文档影响检查](./02-ai-doc-tree-protocol.md)。

- **启用条件**：项目显式指定检查对象（例如哪些模块的架构、哪些文档是否与代码一致）、频率和资源额度。定时触发只能使用这份授权，不能自行扩大范围或额度。
- **仅授权检查**：执行会话只读检查目标仓库；有发现就关联已有待办或创建独立待办，不改代码或文档，不重开已交付的计划。没有发现就结束本次检查。
- **另有修复授权**：范围内的发现可发起独立修复计划，沿用[派工、审查、测试和关票规则](./04-autonomous-skills-testing-and-ci.md)。巡检本身不直接修改主干，修复授权也不等于生产发布授权。
- 巡检使用的 Session 纳入[项目用量统计](./06-session-metering-capabilities.md)；额度耗尽按[中枢恢复规则](./03-hub-agent-dag-and-context-control.md)暂停受影响的工作，不默认打断无关票。
