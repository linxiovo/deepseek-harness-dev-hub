# 22: 从对话暂停或恢复指定分支或整个计划

**执行角色：** backend

**What to build:** 授权人能在项目对话按票、分支或全计划发出暂停/恢复；同时看到哪些动作已经发生、哪些还可以阻止。

**Blocked by:** [19 只在明确授权的环境发布并验证产物](19-authorized-release.md)；[20 停滞或需求改变时保留承诺地重排计划](20-autonomous-replan.md)

**Status:** ready-for-agent

**GitHub 实施票：** [#23](https://github.com/linxiovo/deepseek-harness-dev-hub/issues/23)

**对应规格：** [S22](../spec.md#s22)

**依赖理由：** 19 提供真实发布边界，20 提供有作用域的变更/重排入口；暂停必须与现有派工、合入和发布三个出口一起生效。

## 验收条件

- [ ] 点名票 A 暂停，拦其分支新派工、合入和发布，依赖 A 的后继仍等；无关票 B 继续。明确全停才阻止整个计划。无权限者同样操作无状态变化。
- [ ] 在可取消与已生效的在途动作前后发指令，可分别查询「已请求停止」「已停止」「已经发生」及对应票/计划；已发布不称为自动撤回。
- [ ] 从对话恢复时重查凭据、前置、额度及当前暂停范围；有条件仍缺就保持相应等待。含糊的范围只澄清必要对象；改需求转到先列失效验收的重排流程，不以恢复代替授权。
