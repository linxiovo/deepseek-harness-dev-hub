# 07: 随候选改动交付 Doc Tree 影响判定

**执行角色：** backend

**What to build:** 让 Worker 用 doc-tree 在自己工作树定位最小职责叶子，交付随改动同行的当前说明（含后端接口契约文档），或可被审查者推翻的「无需更新」理由。

**Blocked by:** [03 为每张票交付可验证的独立工作树](03-ticket-worktree.md)

**Status:** ready-for-agent

**GitHub 实施票：** [#8](https://github.com/linxiovo/deepseek-harness-dev-hub/issues/8)

**对应规格：** [S07](../spec.md#s07)、[S33](../spec.md#s33)

**依赖理由：** 需要 03 的单票写入边界来保证文档、接口契约、路由与代码位于同一候选，而不是共同维护一份待合入文档。

## 验收条件

- [ ] 在有导航约定的仓库使用原导航；没有约定时用根/模块旁的 DOCS.md，自动加载的引导仅含入口。根/中间路由只给名称、职责摘要与相对路径；叶子按职责写有内容的契约、约束、代码/验证入口和必要依赖，不按函数建空页。
- [ ] 后端票新增或修改对外 API/数据结构时，必须把接口路径、方法、入参出参、错误码与验证入口写入对应接口契约叶子文档，供后继前端票直接读取消费。
- [ ] 给已知叶子、只知领域名和文档与源码矛盾三类任务：分别直读、循路由定位、定点查证并修正。维护者能沿链接找到唯一权威说明，无需全仓扫描或复制事实。
- [ ] 移动、增加或删除模块并改变其接口，在本票候选中同时看到代码、相关叶子、接口契约和受影响的上级路由变动；行为/依赖/运行或验证事实变化也有对应更新。纯内部改动给短理由，不无故改路由。过时事实原位替换/删除，无历史归档。
- [ ] 对断链、无效入口、不可达节点给出可复验的结构问题；对「链接正确但语义错误」或接口文档与源码不一致不签发语义通过，只把文档差异或无影响理由送独立审查。本票交付文档影响证据，不代签审查。
