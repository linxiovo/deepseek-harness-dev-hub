# 21: 让共享规则通过独立维护票生效

**执行角色：** backend

**What to build:** 本票可改善授权内的检查、测试和导航；要改变其他票也使用的共享规则或团队/用户自定义 Skills，必须由独立维护任务或配置入口验证并发布新版本，不能借改规则逃过检查。

**Blocked by:** [17 凭真实交付证据关票并释放后继](17-close-unlock.md)

**Status:** ready-for-agent

**GitHub 实施票：** [#22](https://github.com/linxiovo/deepseek-harness-dev-hub/issues/22)

**对应规格：** [S20](../spec.md#s20)

**依赖理由：** 17 提供可独立交付或被拒绝的维护票及真实关票检查；规则与自定义 Skills 变更不能在同一张待放行的票里自审自准。

## 验收条件

- [ ] 以规则与自定义 Skills v1 启动两票。其中一票试图热换共享 Skill、自定义 Skill 或全局规则，当前票与重试/重验仍显示绑定 v1。按本票授权修正导航/增加测试可以提交，但需独立审查。
- [ ] 开独立维护票或配置更新验证 v2，由独立会话审查并按交付规则生效。v2 不回写正在运行的任务；此后新任务才可选用已生效的 v2，未通过版本不对外生效。
- [ ] 尝试删除失败检查、降低验收、扩大权限或提高额度来让原票变绿；原失败和阻塞仍在，新规则不授予这些权限。
