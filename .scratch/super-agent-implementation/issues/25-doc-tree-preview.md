## 验收条件

- [ ] 在 main 及配置了其他主干名的仓库中打开默认 Doc Tree 入口，均调用主干路由渲染正文与后端接口契约文档，不把执行目录当作主干。
- [ ] 两票各在工作树更改同一叶子；分别从两票详情跳转或选票预览，页面看到各自工作树路径/分支与醒目「未合入」标示，任何一处都不混入另一票或主干的候选内容。
- [ ] 切回主干视图仍是合入前版本；其中一票合入后刷新只显示该次实际主干内容，未合入的另一票仍隔离，且可在原生对话右侧边栏停靠对比查看。
